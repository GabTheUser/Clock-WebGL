# Clock-WebGL

WebGL-приложение-часы, выполненное как тестовое задание.  
Часы синхронизируются с серверным временем и позволяют пользователю менять время вручную.

🔗 Онлайн-версия: https://gabtheuser.github.io/Clock-WebGL/

## О проекте

При запуске приложение запрашивает текущее время с сервера и синхронизирует часы.  
Дальше пользователь может:

- изменять время, **двигая стрелки** на циферблате;
- **редактировать цифровое представление** времени в полях ввода.

Таким образом демонстрируется связка:

- работы с серверным временем;
- интерактивного UI (аналоговые и цифровые часы);
- обновления состояния в реальном времени прямо в браузере.

## Основные возможности

- Получение и синхронизация времени с сервера при старте.
- Отображение времени в виде:
  - аналоговых часов со стрелками,
  - цифрового формата (часы / минуты / секунды).
- Две формы редактирования:
  - перетаскивание стрелок на циферблате,
  - ручной ввод значений в цифровые поля.
- Мгновенное обновление всех представлений времени при любом изменении.
